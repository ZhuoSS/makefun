`main.py` writes that one line to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`) as UTF-8 with no trailing newline.

```sh
MAKEFUN_OUTPUT_DIR=out python main.py && cat out/entry.txt
```
